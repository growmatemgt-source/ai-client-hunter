# AI Client Hunter — Vercel PWA

IMPORTANT: Open `index.html` locally and the CSS/JS will work because all asset paths are relative (`./...`).

Deploy the same files to GitHub and import the repository into Vercel.

This is the frontend/PWA foundation. Lead data in the demo is stored in browser localStorage. Real AI, lead discovery, email and WhatsApp integrations require official APIs and Vercel environment variables.

Install: after HTTPS deployment, supported browsers can install the PWA / Add to Home Screen.

No spam, CAPTCHA bypass, login scraping or platform-rule evasion.
